# 📓 Notebooks

Thư mục chứa các Jupyter Notebooks dùng để thí nghiệm và trực quan hóa:

| Notebook | Mô tả |
|----------|-------|
| `01_eda.ipynb` | Khám phá dữ liệu (EDA): phân bố, correlation, thống kê |
| `02_model_experiments.ipynb` | Thí nghiệm huấn luyện và so sánh các mô hình |

## Cách chạy

```bash
cd notebooks
jupyter notebook
```

> **Lưu ý**: Đảm bảo đã cài đặt dependencies trong `requirements.txt` trước khi chạy.
